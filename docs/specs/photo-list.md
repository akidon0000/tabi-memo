# 画面仕様: 写真の一覧

- 読み手: 実装者・確認者(本人・エージェント)
- 確認: iPhone 18 Pro シミュレーター、2026-10-04。リストとグリッドの2案を見比べるため、どちらも実装している(決まったら1つにする)

## 入口

地図右上の「…」→「写真の一覧」(「最近取り除いた項目」の上)。シートで開く。

## 見た目(2案)

上部の切り替えで、リストとグリッドを行き来できる。選んだ表示は次回も残る。

| 表示 | 内容 |
|---|---|
| リスト | 行ごとに、サムネイル(56pt)、タイトル(無ければ「タイトルなし」)、撮影日時。撮影順 |
| グリッド | 3列の正方形サムネイル。撮影順 |

地図に写真が無いときは「写真はまだありません」。

## 操作

| 操作 | リスト | グリッド |
|---|---|---|
| 開く | 行をタップ | サムネイルをタップ |
| 編集 | 行を右へスワイプ、または編集モードで | 長押しメニュー「編集」 |
| 削除 | 行を左へスワイプ | 長押しメニュー「削除」 |
| 並べ替え | 右上「編集」を押し、行の右端をドラッグ | サムネイルを別のサムネイルへドラッグして落とす |

- 開く: 一覧を閉じ、その写真のパネル(コンパクト)を開き、地図もその場所へ動かす。ピンを押したときと同じ。
- 編集: 編集シート(日時・場所・タイトル・メモ)。
- 削除: 写真のゴミ箱と同じ確認(「削除した写真は『最近取り除いた項目』に7日間残ります」)を出し、「最近取り除いた項目」へ移す。
- 並べ替え: 写真は日時の順で並ぶので、並べ替えは日時の割り当て直しで表す(日時の集合は変わらず、並びの順に割り当てる)。
