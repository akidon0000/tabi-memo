# 画面仕様: トリップの一覧

- 読み手: 実装者・確認者(本人・エージェント)
- 目的: アプリの最初の画面(トリップの一覧)の挙動を定義する
- 要件: [0007](../requirements/0007-trip-list.md)。設計の理由: [ADR 0019](../adr/0019-multiple-trips.md)
- 確認: iPhone 18 Pro(iOS 27)シミュレーター、2026-10-11

## 1. 構成

| 場所 | 内容 |
|---|---|
| 左上「…」 | 「最近削除したトリップ」「見た目の設定」 |
| 右上「+」 | 新しいトリップを作る(名前を入れるアラート) |
| 一覧 | 各トリップの表紙(最初の写真。無ければ地図アイコン)・名前・期間(最初〜最後の写真の日。同じ日なら1日だけ。写真が無ければ作った日) |

見た目は、リスト・カード・グリッドから、並び順は、作った日の新しい順・旅の日付の新しい順・名前順から選ぶ(見た目の設定)。

## 2. 操作

| 操作 | 挙動 |
|---|---|
| 行を押す | そのトリップの地図画面へ進む。地図からは戻るボタンで一覧へ戻る |
| 「+」→ 名前を入れて作成 | 空のトリップを作り、その地図を開く。名前が空なら「新しいトリップ」 |
| 行を長押し(または左へスワイプ)→ 名前を変える | 名前を直す。空の名前にはならない |
| 行を長押し(または左へスワイプ)→ 削除 | 一覧から外れ、「最近削除したトリップ」へ移る。確認は出さない(戻せるため) |
| 「…」→ 最近削除したトリップ | 削除したトリップを、新しく削除した順に出す。「元に戻す」「完全に削除」(確認あり)。あと何日で完全に消えるかも出す |

- トリップが1つも無いときは「トリップがありません」と、「+」で作る案内を出す。
- 一覧を開いたとき1回、保持期間を過ぎた削除済みのトリップを完全に消す。
- 地図画面を開いたとき、写真が1枚も無いトリップは、現在地の周り(許可が無ければ東京)を出す。

## 3. 見た目の設定

[AppearanceSettings.swift](https://github.com/akidon0000/tabi-memo/blob/main/App/Features/Sources/SharedUI/Settings/AppearanceSettings.swift) の選択肢を、アプリ内で切り替えて見比べる。決めたら、使わない案を消す。

| 項目 | 案 |
|---|---|
| 一覧の見た目 | リスト / カード / グリッド |
| 一覧の並び順 | 作った日の新しい順 / 旅の日付の新しい順 / 名前順 |
| 地図の「一覧へ戻る」 | 左上の丸いボタン / 「…」メニューの中 |
| 「+」を押したときの選び方 | 下から出るメニュー / 大きな2ボタンの小さなシート |
| カメラ | シャッター(白い輪 / ガラスの丸)、完了ボタン(右下 / 右上)、撮った枚数(サムネイル / 数字だけ) |
