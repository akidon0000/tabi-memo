# 0006: 写真の追加は、複数選択 → 横にめくる詳細モーダル → 一括保存にする

- 状態: 有効
- 読み手: 将来の自分・エージェント
- 日付: 2026-10-04

## 決定

- 右下の「＋」で写真ピッカー(複数選択)を開く。選び終えると、詳細入力のモーダルが読み込み中の状態で先に開く。
- 詳細入力は1つのモーダルで、選んだ枚数ぶんを横にめくる。「すべて保存」でまとめて保存する(保存前に落ちると入力は消える。閉じるときは破棄の確認を出す)。
- 項目は日時・位置・タイトル・メモの4つ。`TripPhoto` に `title` を足した。
- 日時と GPS は画像のメタデータ(ImageIO)から自動入力する。GPS がなければ、地図でピンを置いてもらう。地図は撮影時刻が前後する写真の位置(中間点)へ先に動く。
- タイトル案と解説は AI が画像から作る。端末内モデルを先に試し、使えなければ Private Cloud Compute(PCC)に切り替える。どちらも使えなければ提案欄を出さない。反映は「提案を使う」を押したときだけ。

## 比較

| 案 | 採否 | 理由 |
|---|---|---|
| 1枚だけ選ぶ | 不採用 | 旅のあとでまとめて登録する使い方に合わない |
| 1枚ずつ別モーダルで保存 | 不採用 | 全体を行き来して直せない |
| 横にめくって一括保存 | 採用 | 行き来できる。代わりに保存前の中断で消える |
| PCC は使えない前提で端末内のみ | 不採用 | iOS 27 の SDK に `PrivateCloudComputeLanguageModel` があった。非対応機種の補いになる |

## 割り切り

- PCC と画像入力は iOS 27 以降。デプロイ先は iOS 26 のままなので、`#available(iOS 27.0, *)` で守っている。
- 提案は表示中とその次のページだけ先に作る(PCC の利用枠が尽きるのを避ける)。
- 提案の実機での動作は未確認。シミュレーターでは端末内モデルが使えず、提案欄は出ない(手入力のみで動くことは確認した)。
