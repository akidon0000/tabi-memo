# 0018: 全開のパネルは、ステータスバーの裏まで伸ばす

- 状態: 有効
- 読み手: 将来の自分・エージェント
- 日付: 2026-10-11

## 決定

下のパネルが全開に近づくとき、パネルの上端を画面の一番上まで上げ続ける。ステータスバーの裏もパネルの白い面にし、上の角は端末の画面角にそろえる。中身(×・写真・日時・メモ)の位置は、これまでと同じ(上のセーフエリアの下から始まる)。

## 背景

これまでは、パネルが上のセーフエリアの手前で止まり、ステータスバーの部分だけ別の白い帯が `fullProgress` でフェードして重なっていた。パネルが上がっているのに、ステータスバー側だけ別の動きで色が変わり、1つの面が上がっていくように見えなかった。参考のサンプル動画では、パネルの面がそのままステータスバーの裏まで続いていた。

## 比較

実機で見比べるために、全開の上端のつなぎ方を4案作り、「…」メニューで切り替えて試した(試作は削除済み)。

| 案 | 内容 | 採否 |
|---|---|---|
| 現状 | 手前で止め、白い帯をフェード | 不採用(上の理由) |
| A | 上端まで伸ばす。ステータスバーの部分も白 | 採用 |
| B | 上端まで伸ばす。ステータスバーの部分はガラスのまま | 不採用(写真の色味で時刻・電池が読みにくくなりうる) |
| C | A と同じ見た目で、全開の半分の時点で上端に着く | 不採用(伸び方が不自然に速い) |

## 決めたこと・割り切り

- 全開の高さ(`heights.full`)は変えず、描画だけ `fullProgress × 上のセーフエリア` ぶん上へ伸ばす。中身はその分下げるので、スクロール量・ドラッグ量の計算は変わらない。
- 角の丸みは `lerp(同心の丸み, 画面角, fullProgress)`。全開では余白が 0 なので、同心の式(画面角 − 余白)がそのまま画面角になる。
- ステータスバーの文字(時刻・電池)の色は、システムが下の面の明るさで決める。
