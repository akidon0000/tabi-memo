# 0001: 当面は地図画面だけに絞る

- 状態: 有効
- 読み手: 将来の自分・エージェント
- 日付: 2026-10-02
- ブランチ: `feature/map-only`

## 決定

一覧画面（TripListView）・リプレイ画面（ReplayView）と、リプレイ用のモデル・サービスを外し、起動直後に地図画面（TripDetailView）だけが開く構成にする。

## 背景

地図の下に出す写真パネルの操作感を詰めたい。一覧やリプレイが同じビルドにあると、確認のたびに画面遷移が挟まり、変更の影響範囲も広い。

## 比較

| 案 | 内容 | 採否 |
|---|---|---|
| A. 今の変更を別ブランチに退避し、新ブランチで削る | main は無傷。戻せる | 採用 |
| B. 地図画面だけの実験ブランチを main から切る | 退避する変更が無いときに有効 | 今回は変更があったため不採用 |
| C. 動画再現用の別 View を足す | 地図画面はそのまま | 不採用（地図画面そのものを作り込みたい） |

## 影響

- 起動時は `MapRootView`（暫定）が、軌跡のあるトリップを直接開く。空のトリップは選ばない。
- リプレイは `main` 側に残っている。戻すときは、このブランチの削除コミットを元に戻すか、`main` から必要分を取り込む。
- Xcode プロジェクトは Tuist 生成物（git 管理外）。ファイルを増減したら `tuist generate` が要る。

## 見直しのタイミング

パネルの作り込みが終わり、一覧・リプレイと統合するとき。
