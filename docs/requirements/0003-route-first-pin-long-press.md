# 要件 0003: 道なりの線・最初のピンの選択・長押しで追加

- 状態: 確定(2026-10-05)。実装済み・Build 3 で TestFlight に配信
- 元の依頼: 2026-10-05 のチャット(FB ではなく、開発者本人の依頼)
- 読み手: 将来の自分・エージェント

## 決めた要件

| ID | 内容 | 決めたこと |
|---|---|---|
| R-1 | 写真を撮影順に結ぶ白い破線を、道に沿わせる | 隣り合う写真の区間ごとに、MapKit の経路検索で道なりの経路を求めて描く。徒歩で求め、無ければ車で求める。どちらも求められない区間(電車・飛行機・圏外など)は直線のまま。青い軌跡は、実データなのでそのまま描く |
| R-2 | 開いたとき、最初のピンが選ばれている | 撮影順で最初の写真を選び、下のパネルをコンパクトで出し、地図もそのスポットへ動かす。起動のたびに1回だけ。取り除いたあとに別の写真を自動で選び直すことはしない(最後の1枚を取り除くとパネルが閉じる、は変えない) |
| R-3 | 地図を長押しして、その場所に写真を追加する | 0.5秒の長押しで写真ピッカーを開く。選んだ写真は、すべて長押しした位置に置く(写真の位置情報より優先。「位置は手動で指定されました」の扱い)。位置は、あとから追加画面の「場所」で直せる |

## 受け入れ条件

- 開いた直後、最初の写真のパネルがコンパクトで出ていて、そのピンが画面の上から 1/3 あたりに見える。
- 白い破線が、直線ではなく道に沿って曲がる。写真を足すと、足した区間だけ道なりに延びる。
- 地図の何もない場所を長押しすると写真ピッカーが開く。選んで保存すると、押した場所の近くにピンが立つ。「+」から追加したときは、いままでどおり写真の位置情報から決まる。

## やらないこと・割り切り

- 経路を端末に保存すること。アプリを開き直すと求め直す。求められなかった区間は、アプリを閉じるまで求め直さない。
- 移動手段を選ぶこと。電車や飛行機の区間は直線のまま(MapKit の経路検索が徒歩と車だけのため)。
- 長押しした場所に、写真を選ぶ前の目印を出すこと(触覚のフィードバックだけ)。
- 位置情報の取り込み(HealthKit・写真ライブラリの位置と時刻・Google のタイムライン)。要件を別に書く。
