# 要件 0006: パネルの見た目の整理と、再生の操作

- 状態: 確定(2026-10-11)。実装済み・未配信。未決定だった点は、下の表のとおり暫定で決めて実装した
- 元の FB: [2026-10-11](../feedback/2026-10-11.md)(FB-10〜FB-17)
- 読み手: 将来の自分・エージェント

## 困りごと

実機で触ったところ、下部パネルのグラバー(ドラッグバー)が短く、全開の下矢印はグラバーと役割が重なり、コンパクトの黄色の色味が目立つ。再生では、進行方向の矢印は要らず、速さと地図の縮尺を自分で変えられない。写真の場所で止まって拡大する動きは、終わりに向けて減速し、ステータスバーの裏には写真が届かない。

## 要件

| ID | 内容 | 決めたこと |
|---|---|---|
| FB-10 | グラバーを長くする | 見た目の棒の横幅を、いまの48ptより広げる。反応範囲は変えない。具体的な長さは実機で見て決める |
| FB-11 | 全開の下矢印(畳むボタン)を消す | 全開から畳む操作は、グラバーのドラッグ・タップと、下スクロール(FB-8)だけになる。代わりの手段は足さない |
| FB-12 | パネルの黄色をやめる | ガラスに色をかけず、純正のまま。コンパクト・ハーフ・全開で同じ(設定がひとつなので、コンパクトだけ変えない) |
| FB-13 | 再生中の目印から進行方向を外す | 矢印をやめ、向きを持たない青い丸にする |
| FB-14 | 再生のスピードを変える | 再生中に出るスライダーで、動いている間の速さを無段階に変える。写真で止まる2秒は固定 |
| FB-15 | 再生中に地図の縮尺を変える | ピンチで拡大縮小できる。地図を指で動かすことはできず、目印の追尾は続く。変えた拡大率は再生が終わるまで保つ |
| FB-16 | 再生中の写真の拡大を、一定の速さで広げる | 開くときだけ一定速度(線形)。はじめの大きさ(60%)と時間(0.45秒)はそのまま。閉じるときは今のまま。丸い角は残す |
| FB-17 | 拡大した写真を、画面の縁いっぱいに広げる | ステータスバーの裏まで写真が届く。いまの左右・上下24ptの余白はなくす |

## 受け入れ条件

- [ ] グラバーの棒が、いまより長く見える。
- [ ] 全開に下矢印が出ない。グラバーのドラッグ・タップと下スクロールで畳める。
- [ ] コンパクト・ハーフ・全開のパネルに黄色味がない。
- [ ] 再生中の目印が、進行方向で回らない青い丸のまま線に沿って進む。
- [ ] 再生中にスライダーを動かすと、目印の進む速さが変わる。写真で止まる時間は2秒のまま。
- [ ] 写真の場所で止まって拡大するとき、広がり方が終わりに向けてゆっくりにならず、一定の速さで広がる。閉じるときは今までどおり。
- [ ] 拡大しきった写真が、ステータスバーの裏を含む画面の縁まで届く。角は丸いまま。
- [ ] 再生中にピンチで地図を拡大縮小でき、目印が中心に居続ける。指で地図を動かしても中心はずれない。

## やらないこと

- 全開を畳む新しいボタンの追加。(グラバーのタップで畳める挙動は、下矢印の代わりとして足した。)
- 再生中の地図の平行移動(追尾をやめて自由に動かす案は採らない)。
- 写真で止まる時間の変更。

## 決めたこと・決めていないこと

| 論点 | 決定 | 理由 |
|---|---|---|
| 「グラバーを伸ばす」の意味 | 見た目の棒を長く | 質問に対するユーザーの回答 |
| 下矢印を消した後の畳む手段 | 足さない | 同上 |
| 黄色をやめる範囲 | 3つの高さ全部、色なし | 色の設定が1つで、そろえるのが自然(回答は「色なし」) |
| スピードの操作 | スライダー(無段階) | 同上 |
| 縮尺の操作中の追尾 | 追尾は続く | 同上 |
| 停止中の2秒 | 固定 | 同上 |
| 拡大のアニメーション | 開くときだけ線形、閉じるときは今のまま | 質問に対するユーザーの回答 |
| 拡大の範囲 | 画面の縁いっぱい | 同上 |
| 縁いっぱいのときの写真の収め方 | 画面を埋める(fill)。角の丸みは 56pt | 暫定。実機で見て直す |
| スライダーの範囲・置き場所 | 0.5x〜4x(1x が今の速さ)。画面の下のガラスのカプセル | 暫定。実機で触って直す |
