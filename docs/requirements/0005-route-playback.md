- 元の依頼: 2026-10-05 のチャット(「main にもあった再生ボタンを「…」の隣に置いて、再生すると線に沿って移動する機能」)

以前の再生(カメラが軌跡を飛ぶ版。`e605733`)は、地図画面だけに絞った時点で外してあった([ADR 0001](../adr/0001-map-screen-only.md))。今回はそれを戻すのではなく、いまの構成で、必要な分だけ新しく作った。

## 決めた要件

| ID | 内容 | 決めたこと |
|---|---|---|
| R-12 | 右上の「…」の左に、再生ボタン(▶)を置く | 写真を結ぶ線が引かれているとき(写真が2枚以上)だけ押せる |
| R-13 | 押すと、線に沿って目印が動く | 青い線の上を、進行方向を向く青い丸の矢印が、始点から終点まで進む。地図のカメラは目印を追い、拡大率は押した時点のまま。動いている間の長さは、道のりによらずおよそ20秒(遅くとも秒速30m。写真で止まる時間は含まない) |
| R-14 | 写真の場所で止まり、写真を拡大して見せる | 目印が写真の場所に着くたびに、その写真を画面いっぱいに拡大して2秒見せる(始点の写真でも)。2秒たつと拡大を閉じ、再生を再開する。同じ場所の写真は1回だけ(先の写真を見せる)。拡大中は触れない |
| R-15 | 止め方・終わり方 | 再生中は右上が停止ボタン(■)だけになる。押すと止まり、パネルと「…」が戻る。終点で止まり終えると自動で終わる |
| R-16 | 再生中の画面 | 下のパネルと追加ボタン、「…」は隠す。地図は指で動かせず、ピンも押せない |

## 受け入れ条件

- 線が引かれているとき、▶ が「…」の左に出る。写真が1枚以下のときは押せない。
- ▶ を押すと、目印が線に沿って動き、地図が追いかける。
- 目印が写真の場所に着くと、その写真が拡大して2秒出て、閉じて再生が再開する。
- ■ を押すと止まり、元の画面に戻る。最後まで進むと自動で戻る。

## やらないこと・割り切り

- 一時停止・再開、速度の切り替え、巻き戻し。
- 拡大中の写真の操作(ピンチ・閉じるなど)。再生中の拡大は、見せるだけ。
- カメラの傾き・向きを進行方向に合わせること(地図は北が上のまま)。
- 動画の書き出し・BGM([ROADMAP](../../ROADMAP.md) に残る)。
