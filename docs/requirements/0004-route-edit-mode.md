# 要件 0004: 経路編集モード

- 状態: 確定(2026-10-05)。実装済み・TestFlight 未配信。モードの出入りは2案を実装して見比べ中
- 元の依頼: 2026-10-05 のチャット(開発者本人の依頼)。「…」メニューに経路編集モードを作り、経路を長押ししてドラッグすると、経路(道)を変えられる
- 読み手: 将来の自分・エージェント

## 決めた要件

| ID | 内容 | 決めたこと |
|---|---|---|
| R-5 | 右上「…」メニューに「経路を編集」を足す | 押すと経路編集モードに入る。上に「経路を編集中」の帯と「完了」を出す。編集中は、写真パネルと追加ボタン、「…」を隠す。ピンは押しても開かない |
| R-6 | 白い破線を長押ししてドラッグすると、経路が変わる | 指を離した場所を「通る点(経由点)」にして、その前後を道なりに引き直す(Google マップの経路のドラッグと同じ)。0.4秒の長押しのあとのドラッグで足す |
| R-7 | 経由点を動かす・消す | 経由点は白い丸で出す。長押しのあとのドラッグで動かし、タップで消す。消すと、その区間は自動の経路に戻る |
| R-8 | 直した経路を保存する | 端末に保存する。写真の組(出発の写真と到着の写真)ごとに、経由点を通る順に持つ。写真の位置を動かしても、経由点は残る(ADR 0015) |
| R-9 | モードの出入り(2案を実装して比べる) | 案A: 編集中は地図の移動・拡大を止める。案B: 編集中も地図を動かせる。「…」メニューの「経路の編集中は地図を動かさない」で切り替える(初期は案A)。どちらにするか決まったら、切り替えをなくして1つにする |

## 受け入れ条件

- 「…」→「経路を編集」で帯が出て、パネルと「+」が消える。「完了」で戻る。
- 白い破線を長押ししてドラッグすると、指を離した場所に白い丸が付き、線がそこを通る道なりに変わる。
- アプリを閉じて開き直しても、白い丸と線が残る。
- 白い丸をタップすると消え、線がその区間だけ自動の経路に戻る。
- 案Aでは、編集中に地図がスワイプで動かない。案Bでは動く。

## やらないこと・割り切り

- 青い軌跡(実データ)の編集。直せるのは、写真を結ぶ白い破線だけ。
- 経由点を足すときの、ドラッグ中の線のプレビュー(指の位置に白い丸を出すだけ。離したあとに道なりに引き直す)。
- 写真を取り除いたり、撮影順が変わったりして、写真の組が変わったときの経由点の引き継ぎ。組が合わなくなった直しは使われないだけで、残る。
- 元に戻す(アンドゥ)。経由点をタップで消すことで戻す。
