# 要件 0008: アプリ内カメラでの撮影

- 状態: 確認待ち(2026-10-11)
- 元の FB: [2026-10-11](../feedback/2026-10-11.md)(FB-19。「プラス押したら、カメラ起動かライブラリか選択できる」)
- 読み手: 将来の自分・エージェント

## 困りごと

写真を足すには、いったん別のカメラで撮って、ライブラリから選び直す必要がある。旅先でその場で撮って、そのまま地図に置けない。

## 要件

| ID | 内容 | 決めたこと |
|---|---|---|
| C-1 | 「+」を押したら、カメラで撮るか、ライブラリから選ぶかを選べる | 地図の長押しで場所を指定して追加するときも同じ選択を出す |
| C-2 | アプリ内のカメラで撮る | 自前のカメラ(AVFoundation)。何枚でも続けて撮れ、「完了」で終える |
| C-3 | カメラの機能 | ワイド・超広角などのレンズ切り替えとピンチズーム、インカメラ/アウトカメラの切り替え、フラッシュのオン・オフ、タップでピント |
| C-4 | 撮ったあと | 「完了」を押したところで、撮った写真をまとめて、いまの追加フォーム(日時・タイトル・メモ・並べ替え)へ進める。ライブラリで複数選んだときと同じ流れ |
| C-5 | 位置 | 撮った瞬間の現在地を、その写真の位置にする。長押しで場所を指定していれば、そちらを優先する |
| C-6 | 端末への保存 | 撮った写真は、端末の写真ライブラリにも保存する |

## 受け入れ条件

- [ ] 「+」を押すと、「カメラで撮る」「ライブラリから選ぶ」が出る。ライブラリは今までどおり。
- [ ] カメラが起動し、プレビューが出る。シャッターで撮れて、続けて何枚でも撮れる。
- [ ] レンズ切り替え・ピンチズーム・インカメラ切り替え・フラッシュ・タップでピントが動く。
- [ ] 「完了」で追加フォームが開き、撮った写真が並ぶ。保存すると、現在地のピンとして地図に出る。
- [ ] 端末の写真アプリにも、撮った写真が入っている。
- [ ] 位置情報の許可がないときは、許可を求める。拒否されても、撮れて、位置だけ地図で指定できる(長押しの追加と同じ)。

## やらないこと

- 動画の撮影、ライブフォト、人物モード、露出・ホワイトバランスの手動調整。
- 撮影後のその場での画像編集(トリミング・フィルター)。
- 撮影中に、撮った写真の確認・削除をカメラ画面で行うこと(完了後のフォームで並べ替え・削除する)。

## 決めたこと・決めていないこと

| 論点 | 決定 | 理由 |
|---|---|---|
| カメラの作り | 自前(AVFoundation) | 質問に対するユーザーの回答 |
| 撮影後の流れ | まとめて追加フォームへ | 同上 |
| 機能 | レンズ・ピンチ・インカメ・フラッシュ・タップでピント | 同上 |
| 位置と保存 | 現在地を位置にし、写真ライブラリにも保存 | 同上 |
| 撮った写真の日時 | 撮影した時刻。フォームで直せる(ライブラリと同じ) | 既存の追加フォームの挙動に合わせる |
| カメラ画面の見た目(ボタン配置・完了ボタン・枚数の表示) | **未決定** | 実機で見ながら決める |
| 位置情報の許可を拒否されたときの案内の文面 | **未決定** | 実装時に決める |

## 影響

- 新しい画面: カメラ(`CameraFeature`)。地図画面の「+」から開く。追加フォームは、ライブラリの項目だけでなく、撮った画像も受け取れるようにする。
- 許可: カメラ(`NSCameraUsageDescription` は Info.plist にある)、位置情報(使用中のみ。Info.plist にある)、写真ライブラリへの追加(`NSPhotoLibraryAddUsageDescription` を足す)。
- 残すべき ADR: 自前カメラ(AVFoundation)の採用と、撮影した写真の取り込み方(新番号で起票)。
- 前提が変わる記録: [map-screen.md](../specs/map-screen.md)、[add-photos.md](../specs/add-photos.md)。
